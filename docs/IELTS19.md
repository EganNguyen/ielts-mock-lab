# IELTS 19 Academic — static mock pack

Four complete Academic practice tests extracted from the user-provided
`IELTS 19 Academic.pdf` and compiled into the Apex exam schema. This pack is
**static-only**: it ships in the browser build and is not embedded in the Go API or
seeded into PostgreSQL.

> **Private study only.** The source book prohibits reproduction without permission from
> Cambridge University Press & Assessment. The GitHub Pages deployment is public; only
> publish this content if you have confirmed redistribution rights.

## Source materials

- File: `/Users/tim2k/Downloads/IELTS 19 Academic.pdf`
- PDF: 139 pages, A4, encrypted with copy disabled but printing allowed.
- The PDF is a scan with a partial text layer: front matter and a few question pages
  have selectable text, most test pages do not. `pdftotext` was therefore used only for
  the page map; all content was OCR'd from 200 dpi page images.
- OCR used Tesseract 5 (`--psm 3` for passages, `--psm 6` for keys/scripts) with Apple
  Vision OCR as a cross-check. The results were then manually spot-checked against the
  page images.

## Rebuilding

```bash
cd content/ielts19
python3 tools/extract.py         # transcripts + metadata from OCR
python3 tools/passages.py        # cleaned reading passages
python3 tools/build_content.py   # validates and writes content/academic/*.json
python3 tools/audit_fidelity.py  # OCR text-overlap audit
```

Generate audio only when transcripts change:

```bash
../../.venv-kokoro/bin/python tools/generate_audio.py
../../.venv-kokoro/bin/python tools/generate_speaking.py
```

Static build:

```bash
bash scripts/export-static.sh
```

## Verification

- `build_content.py`: 4/4 tests, 40 Listening + 40 Reading each, all `{{n}}` blanks
  matched, 2 Writing tasks, 3 Speaking parts.
- `audit_fidelity.py`: 5 residual findings, all generic paraphrased completion prompts;
  no mismatched passages, options or quoted statements.
- Static full-flow browser test: all four IELTS 19 tests scored **80/80**, rendered the
  results page, and produced no console/page errors after audio was available.
- Listening audio: 16 part MP3s generated with Kokoro; examiner audio for all four tests.

## Source defects and OCR repairs

- Answer keys are printed in a two-column layout; several key digits were missed by
  Vision OCR. The keys were transcribed directly from the page images and checked
  against the question numbering (40 answers per skill).
- Running heads (`Test N`, `Listening`, `Reading`), Telegram watermarks, question-margin
  markers (`Q1`, `Ql`, `Qg`) and page numbers were stripped from transcripts.
- OCR speaker variants (`coLemMAN`, `coteman`, `cHaRLoTTE`) were normalised.
- The scan uses an em dash where the source has a hyphen; punctuation was normalised.
- The Test 1 Listening Part 2 map was cropped from page 12 and checked at full size.

## Known limitations

- OCR is not perfect. A handful of proper nouns and punctuation marks may differ from
  the printed book; the fidelity audit and manual spot-check cover the question text,
  answer keys and passage bodies.
- The generated listening parts run roughly 4–5 minutes each, shorter than a real IELTS
  recording.
- Table layouts are flattened into labelled bullet rows for the on-screen runner.
- Writing Task 1 is delivered as a high-resolution crop of the book figure.
- Writing and Speaking bands are local rubric estimates, not official IELTS results.
- Sample Writing answers and answer sheets are present in the PDF but not wired into
  the app.
