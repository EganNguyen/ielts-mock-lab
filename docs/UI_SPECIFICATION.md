# UI Notes

- Candidate surfaces use a cream editorial dashboard and a neutral, high-contrast exam shell.
- No hints, grammar correction, answer keys or scoring feedback appear during a test.
- Question navigation uses a numbered palette with answered/flagged states.
- The listening player has no pause/replay/seek control; a refresh restores position and requires a deliberate resume action.
- Reading provides independent passage/question scrolling, text-size controls and CSS Custom Highlight selection.
- Writing shows word counts and autosave status but no spellcheck/grammar assistance.
- Speaking uses an examiner card, cue card, preparation and long-turn timers, and records each answer locally.
- Results are marked “Estimated result — not an official IELTS score.”
